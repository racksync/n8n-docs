วิธี pin data ใน node:

1. รัน node เพื่อโหลด data
2. ในมุมมอง **OUTPUT** เลือก **Pin data** <span class="inline-image">![Pin data icon](/_images/data/data-pinning/data-pinning-button.png){.off-glb}</span> เมื่อการ pin data ทำงานอยู่ ปุ่มจะถูกปิดใช้งานและแบนเนอร์ "This data is pinned" จะแสดงในมุมมอง **OUTPUT**
