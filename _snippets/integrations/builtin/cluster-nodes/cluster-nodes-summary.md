[Cluster nodes](/glossary.md#cluster-node-n8n) คือกลุ่มของ node ที่ทำงานร่วมกันเพื่อมอบฟังก์ชันการทำงานใน workflow ของ n8n แทนที่จะใช้ node เดียว คุณจะใช้ [root node](/glossary.md#root-node-n8n) และ [sub-nodes](/glossary.md#sub-node-n8n) หนึ่งรายการหรือมากกว่าเพื่อขยายฟังก์ชันการทำงานของ node
