/// info | Feature availability
* Available on Enterprise plans.
* คุณต้องมีสิทธิ์เข้าถึงบัญชี owner ของ n8n instance เพื่อเปิดใช้งานและกำหนดค่า SAML

Available from version 0.225.0.
///	

ส่วนนี้ให้คำแนะนำเกี่ยวกับการใช้ SAML SSO (single sign-on) กับ n8n โดยสมมติว่าคุณคุ้นเคยกับ SAML อยู่แล้ว หากยังไม่คุ้นเคย [SAML Explained in Plain English](https://www.onelogin.com/learn/saml){:target=_blank .external-link} สามารถช่วยให้คุณเข้าใจวิธีการทำงานของ SAML และประโยชน์ของมันได้

* [Set up SAML](/user-management/saml/setup.md): คำแนะนำทั่วไปเกี่ยวกับการตั้งค่า SAML ใน n8n และลิงก์ไปยังแหล่งข้อมูลสำหรับ IdPs ทั่วไป เริ่มต้นที่นี่
* [Okta Workforce Identity SAML setup](/user-management/saml/okta.md): คำแนะนำทีละขั้นตอนในการกำหนดค่า Okta
* [Troubleshooting](/user-management/saml/troubleshooting.md): รายการสิ่งที่ต้องตรวจสอบหากคุณพบปัญหา
* [Managing users with SAML](/user-management/saml/managing.md): การทำงานเกี่ยวกับการจัดการผู้ใช้เมื่อเปิดใช้งาน SAML
