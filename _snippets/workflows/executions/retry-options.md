3. เลือกตัวเลือกใดตัวเลือกหนึ่งต่อไปนี้เพื่อลองรัน execution อีกครั้ง:
    * **Retry with currently saved workflow**: เมื่อคุณทำการเปลี่ยนแปลง workflow ของคุณแล้ว คุณสามารถเลือกตัวเลือกนี้เพื่อรัน workflow ด้วยข้อมูล execution ก่อนหน้า
    * **Retry with original workflow**: หากคุณต้องการลองรัน execution อีกครั้งโดยไม่ต้องทำการเปลี่ยนแปลง workflow ของคุณ คุณสามารถเลือกตัวเลือกนี้เพื่อลองรัน execution อีกครั้งด้วยข้อมูล execution ก่อนหน้า
