# How can you contribute?

มีหลายวิธีที่คุณสามารถ contribute ให้กับ n8n ได้ ขึ้นอยู่กับความถนัดและความสนใจของคุณ ทุกการ contribute มีคุณค่ากับเราเสมอ!

## Share some love: Review us

- กด star ให้ n8n บน [GitHub](https://github.com/n8n-io/n8n){:target=_blank class=.external-link} และ [Docker Hub](https://hub.docker.com/r/n8nio/n8n){:target=_blank class=.external-link}
- กด follow เราบน [Twitter](https://twitter.com/n8n_io){:target=_blank class=.external-link}, [LinkedIn](https://www.linkedin.com/company/28491094), และ [Facebook](https://www.facebook.com/n8nio/){:target=_blank class=.external-link}
- กด upvote n8n บน [AlternativeTo](https://alternativeto.net/software/n8n-io/){:target=_blank class=.external-link} และ [Alternative.me](https://alternative.me/n8n-io){:target=_blank class=.external-link}
- เพิ่ม n8n ใน stack ของคุณบน [Stackshare](https://stackshare.io/n8n){:target=_blank class=.external-link}
- เขียนรีวิวเกี่ยวกับ n8n บน [G2](https://www.g2.com/products/n8n/reviews){:target=_blank class=.external-link}, [Slant](https://www.slant.co/improve/options/37977/~n8n-review){:target=_blank class=.external-link}, และ [Capterra](https://www.capterra.com/p/198028/n8n-io/){:target=_blank class=.external-link}

## Contribute to the code

มีหลายวิธีที่คุณจะ contribute ให้กับ code base ของ n8n:

- แก้ [issues](https://github.com/n8n-io/n8n/issues){:target=_blank class=.external-link} ที่มีใน GitHub ดู [CONTRIBUTING guide](https://github.com/n8n-io/n8n/blob/master/CONTRIBUTING.md){:target=_blank class=.external-link} เพื่อเตรียม environment สำหรับพัฒนาได้ในไม่กี่นาที
- เพิ่มฟีเจอร์ให้กับ third party integration ที่มีอยู่แล้ว
- เพิ่มฟีเจอร์ใหม่ให้กับ n8n

## Contribute to the blog

คุณสามารถเขียนบทความให้กับ [n8n blog](https://blog.n8n.io/){:target=_blank class=.external-link} ได้ เช่น [workflow tutorial](https://blog.n8n.io/tag/tutorial/){:target=_blank class=.external-link}, บทความแสดงความคิดเห็นเกี่ยวกับ automation หรือ [automation guides](https://blog.n8n.io/tag/guide/){:target=_blank class=.external-link} เฉพาะทาง

### How to submit a post

n8n ยินดีรับทุก contribution การเผยแพร่ tutorial บนเว็บของคุณเองที่ช่วย community ก็ถือเป็น contribution ที่ดี ถ้าคุณอยากให้ n8n ช่วยโปรโมตโพสต์ของคุณบน blog ให้ทำตามขั้นตอนนี้:

1. ส่งไอเดียของคุณไปที่ [marketing@n8n.io](mailto:marketing@n8n.io) โดยใช้หัวข้ออีเมลว่า "Blog contribution: [Your Topic]"
2. ส่ง draft ของคุณ:
      - เขียนโพสต์ใน Google Doc ตาม [style guide](https://www.notion.so/97dc73436a624933b75ddc941a361b70?pvs=21){:target=_blank class=.external-link}
      - ถ้าโพสต์ของคุณมี workflow ตัวอย่าง ให้ใส่ workflow JSON ใน section แยกต่างหากตอนท้าย
      - ถ้าอยากให้เครดิตผู้เขียน ให้ส่ง Google Doc อีกไฟล์ที่มีชื่อเต็ม, byline สั้น ๆ และรูปภาพของคุณ n8n จะใช้ข้อมูลนี้สร้างหน้า author และให้เครดิตคุณในโพสต์
3. รอรับ feedback ถ้า draft ของคุณตรงกับกลยุทธ์และข้อกำหนดของ blog เราจะติดต่อกลับ ถ้าไม่ได้รับการตอบกลับภายใน 30 วัน แปลว่าเราไม่ได้เลือกโพสต์ของคุณ

## Refer a candidate

ถ้าคุณรู้จักใครที่เหมาะกับ [open positions](https://n8n.io/careers){:target=_blank class=.external-link} ของเรา แนะนำเขาให้เราได้เลย! ถ้า referral ของคุณผ่าน probation เราจะโอนเงิน €1,000 ให้คุณ

ขั้นตอนมีดังนี้:

1. **Search**: ดูรายละเอียดและคุณสมบัติของแต่ละตำแหน่ง แล้วคิดดูว่ามีใครที่เหมาะสมบ้าง
2. **Referral**: ถ้าคุณเจอคนที่เหมาะสม ส่งอีเมลไปที่ [Jobs at n8n](mailto:jobs@n8n.io) โดยใช้หัวข้อ *Employee referral - [job title]* พร้อมคำอธิบายสั้น ๆ เกี่ยวกับคนที่คุณแนะนำ (และเหตุผลที่แนะนำ) แล้วบอกให้เพื่อนของคุณสมัครงานผ่าน [careers page](https://n8n.io/careers){:target=_blank class=.external-link} ด้วย
3. **Evaluation**: เราจะตรวจสอบใบสมัครและแจ้งขั้นตอนถัดไปให้คุณทราบ
4. **Reward**: ถ้า referral ของคุณผ่าน probation เราจะโอนเงิน €1,000 ให้คุณเป็นรางวัล
