# Server setups

หน้านี้รวมลิงก์สำหรับวิธีการติดตั้ง n8n แบบ self-host บน server หรือ cloud เจ้าใหญ่ ๆ ที่นิยมใช้กัน ไม่ว่าจะเป็น Digital Ocean, Heroku, Hetzner Cloud หรือถ้าอยากใช้ Kubernetes ก็มีตัวอย่างสำหรับ AWS, Azure, Google Cloud Platform ให้ด้วย

ถ้าอยากตั้งค่าบน platform อื่น ๆ หรือแค่ต้องการ config Docker Compose ธรรมดา ก็มีคู่มือให้เลือกดูได้เหมือนกัน

เลือกหัวข้อที่ตรงกับความต้องการของคุณ แล้วทำตามขั้นตอนได้เลย!

ติดตั้งแบบ Self-host ด้วย Docker Compose:

* [Digital Ocean](/hosting/installation/server-setups/digital-ocean.md)
* [Heroku](/hosting/installation/server-setups/heroku.md)
* [Hetzner Cloud](/hosting/installation/server-setups/hetzner.md)

เริ่มต้นติดตั้งด้วย Kubernetes:

* [AWS](/hosting/installation/server-setups/aws.md)
* [Azure](/hosting/installation/server-setups/azure.md)
* [Google Cloud Platform](/hosting/installation/server-setups/google-cloud.md)

คู่มือการตั้งค่าที่ช่วยให้คุณเริ่มต้นบนแพลตฟอร์มอื่น ๆ:

* [Docker Compose](/hosting/installation/server-setups/docker-compose.md)
