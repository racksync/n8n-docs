# ยินดีสู่คู่มือ n8n ฉบับภาษาไทย


หากคุณคือคนที่เริ่มใช้งาน n8n เว็บไซต์แห่งนี้จะช่วยให้คุณทำความเข้าใจและใช้งาน [n8n](https://n8n.io/){:target=_blank .external-link} (อ่านว่า เอ็น-เอท-เอ็น) อย่างมืออาชีพ ซึ่ง n8n เป็นเครื่องมือ workflow automation ที่ได้รับ license แบบ [fair-code](https://faircode.io){:target=_blank .external-link} ที่รวมความสามารถของ AI เข้ากับการทำงานอัตโนมัติของกระบวนการทางธุรกิจ โดยชื่อ n8n ย่อมาจาก nodemation ซึ่งเป็นชื่อที่ตั้งตามหลักการตั้งชื่อของโครงการโอเพนซอร์ส

เนื้อหาครอบคลุมทุกอย่างตั้งแต่การตั้งค่าไปจนถึงการใช้งานและการพัฒนา เป็นงานที่กำลังดำเนินการอยู่ และยินดีรับ [contributions](/help-community/contributing.md) ทั้งหมด

## สิ่งที่คุณจะได้เรียนรู้

- การใช้งานพื้นฐานของ n8n
- การสร้าง workflows ที่ซับซ้อน
- การเชื่อมต่อกับ APIs ต่างๆ
- การใช้ฟีเจอร์ AI ใน n8n
- การสร้าง custom nodes
- การจัดการข้อมูลด้วยโค้ดเพียงเล็กน้อยหรือไม่ต้องใช้โค้ดเลย
- การใช้งาน n8n บน Cloud หรือ self-host
- สารพัด AI tools ที่ n8n รองรับ
