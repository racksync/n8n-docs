## Operations

* Message
    * Delete a message
    * Get a message
    * Send a private message
    * Send a message to stream
    * Update a message
    * Upload a file
* Stream
    * Create a stream.
    * Delete a stream.
    * Get all streams.
    * Get subscribed streams.
    * Update a stream.
* User
    * Create a user.
    * Deactivate a user.
    * Get a user.
    * Get all users.
    * Update a user.
