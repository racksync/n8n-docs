# Affinity credentials

คุณสามารถใช้ credentials นี้เพื่อเชื่อมต่อกับ node เหล่านี้ได้:

- [Affinity](/integrations/builtin/app-nodes/n8n-nodes-base.affinity.md)
- [Affinity Trigger](/integrations/builtin/trigger-nodes/n8n-nodes-base.affinitytrigger.md)

## Prerequisites

สมัคร [Affinity](https://www.affinity.co/){:target=_blank .external-link} ที่แพลน Scale, Advanced หรือ Enterprise

## Supported authentication methods

- API key

## Related resources

ดูข้อมูลเพิ่มเติมเกี่ยวกับการใช้งาน API ได้ที่ [Affinity's API documentation](https://support.affinity.co/hc/en-us/sections/360010294532-External-API){:target=_blank .external-link}

## Using API key

ถ้าจะตั้งค่า credentials นี้ คุณต้องมี:

- **API Key**: ดูวิธีขอ API key ได้ที่ [How to obtain your Affinity API key documentation](https://support.affinity.co/hc/en-us/articles/360032633992-How-to-obtain-your-Affinity-API-key){:target=_blank .external-link}
