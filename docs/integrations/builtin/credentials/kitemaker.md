# Kitemaker credentials

คุณสามารถใช้ credentials เหล่านี้เพื่อยืนยันตัวตนกับ node ต่อไปนี้ได้:

- [Kitemaker](/integrations/builtin/app-nodes/n8n-nodes-base.kitemaker.md)

## Prerequisites

สร้างบัญชี [Kitemaker](https://www.kitemaker.co/){:target=_blank .external-link}

## Supported authentication methods

- API access token

## Related resources

ดูข้อมูลเพิ่มเติมเกี่ยวกับบริการนี้ได้ที่ [Kitemaker's API documentation](https://kitemakerhq.github.io/rest-docs/){:target=_blank .external-link}

## Using API access token

ในการตั้งค่า credential นี้ คุณจะต้องมี:

- **Personal Access Token**: สร้าง personal access token จาก **Manage > Developer settings** ดูคำแนะนำโดยละเอียดเพิ่มเติมได้ที่ [API Authentication](https://kitemakerhq.github.io/rest-docs/#documentationauthentication){:target=_blank .external-link}
