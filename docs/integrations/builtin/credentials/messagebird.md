# MessageBird credentials

คุณสามารถใช้ credentials เหล่านี้เพื่อยืนยันตัวตนใน nodes ต่อไปนี้:

- [MessageBird](/integrations/builtin/app-nodes/n8n-nodes-base.messagebird.md)

## Prerequisites

สร้างบัญชี [Bird](https://bird.com/){:target=_blank .external-link}

## Supported authentication methods

- API key

## Related resources

อ้างอิง [MessageBird's API documentation](https://docs.bird.com/api){:target=_blank .external-link} สำหรับข้อมูลเพิ่มเติมเกี่ยวกับบริการนี้

## Using API key

ในการกำหนดค่า credential นี้ คุณจะต้องมี:

- **API Key**: หากต้องการสร้าง key ที่เหมาะสม ให้ไปที่หน้า [Access keys](https://app.bird.com/settings/access-keys){:target=_blank .external-link} ใน MessageBird อ้างอิงเอกสาร [API authorization documentation](https://docs.bird.com/api/api-access/api-authorization){:target=_blank .external-link} สำหรับคำแนะนำโดยละเอียด
