# S3 credentials

คุณสามารถใช้ credentials นี้เพื่อเชื่อมต่อกับ node เหล่านี้:

- [S3](/integrations/builtin/app-nodes/n8n-nodes-base.s3.md)

## Prerequisites

สร้าง account บน S3-compatible server ที่คุณต้องการใช้ S3 node นี้สามารถใช้กับ S3 ทั่วไปหรือ non-AWS S3 เช่น:

* [DigitalOcean Spaces](https://www.digitalocean.com/products/spaces){:target="_blank" .external-link}
* [MinIO](https://min.io/){:target="_blank" .external-link}
* [Wasabi](https://wasabi.com/){:target="_blank" .external-link}

## Supported authentication methods

- S3 endpoint

ดูรายละเอียดเพิ่มเติมได้จากเอกสารของ S3-compatible provider ที่คุณใช้งาน เช่น [Wasabi's REST API documentation](https://docs.wasabi.com/docs/rest-api-introduction){:target="_blank" .external-link} หรือ [DigitalOcean's Spaces API Reference Documentation](https://docs.digitalocean.com/reference/api/spaces-api/){:target="_blank" .external-link}

## Using S3 endpoint

ถ้าจะตั้งค่า credentials นี้ คุณต้องมี:

- **S3 Endpoint**: ใส่ URL endpoint สำหรับ S3 storage backend ของคุณ
- **Region**: ใส่ region ของ S3 storage (บาง provider เรียกว่า region slug)
- **Access Key ID**: ใส่ S3 access key ที่ provider ของคุณใช้สำหรับเข้าถึง bucket หรือ space (บาง provider เรียกว่า API keys)
- **Secret Access Key**: ใส่ secret access key ที่คู่กับ **Access Key ID**
- **Force Path Style**: ถ้าเปิด จะใช้ path-style addressing สำหรับ bucket
- **Ignore SSL Issues**: ถ้าเปิด n8n จะเชื่อมต่อแม้ SSL certificate validation จะล้มเหลว

ด้านล่างนี้เป็นวิธีสำหรับ DigitalOcean Spaces และ Wasabi ถ้าใช้ provider อื่นให้ดูเอกสารของ provider นั้น

### Using DigitalOcean Spaces

วิธีตั้งค่า credentials สำหรับ DigitalOcean Spaces:

1. ที่ DigitalOcean ให้ไปที่ control panel แล้วเปิด **Settings** endpoint ของคุณจะอยู่ที่นี่ ให้นำ `https://` ไปต่อหน้า endpoint แล้วใส่เป็น **S3 Endpoint** ใน n8n
    - endpoint ของ DigitalOcean จะขึ้นอยู่กับ region ของ bucket
2. สำหรับ **Region** ให้ใส่ region ที่ bucket ของคุณอยู่ เช่น `nyc3`
    - ถ้าจะใช้ credential นี้เพื่อสร้าง Spaces ใหม่ ให้ใส่ `us-east-1` แทน
3. ที่ control panel ของ DigitalOcean ไปที่ [**API**](https://cloud.digitalocean.com/account/api/spaces){:target="_blank" .external-link}
4. เปิดแท็บ **Spaces Keys**
5. เลือก **Generate New Key**
6. ใส่ **Name** สำหรับ key เช่น `n8n integration` แล้วกดเครื่องหมายถูก
7. คัดลอก **Key** ที่แสดงข้างชื่อ แล้วใส่เป็น **Access Key ID** ใน n8n
8. คัดลอก **Secret** แล้วใส่เป็น **Secret Access Key** ใน n8n
    - ดูวิธีสร้าง key และ secret เพิ่มเติมที่ [Sharing Access to Buckets with Access Keys](https://docs.digitalocean.com/products/spaces/how-to/manage-access/#access-keys){:target="_blank" .external-link}
9. ปกติให้ปิด **Force Path Style** เว้นแต่ต้องการใช้ subdomain/virtual calling format
10. ตัดสินใจว่าจะให้ n8n credential จัดการ SSL อย่างไร:
    - ถ้าต้องการให้เช็ค SSL certificate ตามปกติ ให้ปิด **Ignore SSL Issues**
    - ถ้าต้องการให้เชื่อมต่อแม้ SSL certificate validation จะล้มเหลว ให้เปิด **Ignore SSL Issues**

ดูรายละเอียดเพิ่มเติมที่ [Spaces API Reference Documentation](https://docs.digitalocean.com/reference/api/spaces-api/){:target="_blank" .external-link}

### Using Wasabi

วิธีตั้งค่า credentials สำหรับ Wasabi:

1. สำหรับ **S3 Endpoint** ให้ใส่ service URL ของ region ที่ bucket อยู่ โดยขึ้นต้นด้วย `https://`
    - ดู [What are the service URLs for Wasabi's different storage regions?](https://knowledgebase.wasabi.com/hc/en-us/articles/360015106031-What-are-the-service-URLs-for-Wasabi-s-different-storage-regions){:target="_blank" .external-link} เพื่อดู URL ที่ถูกต้อง
2. สำหรับ **Region** ให้ใส่ region slug ที่อยู่ใน service URL เช่นถ้า **S3 Endpoint** เป็น `https://s3.us-east-2.wasabisys.com` region คือ `us-east-2`
3. ล็อกอินเข้า Wasabi Console เป็น root user
4. เปิด **Menu** แล้วเลือก **Access Keys**
5. เลือก **CREATE NEW ACCESS KEY**
6. เลือกว่าจะสร้าง key สำหรับ **Root User** หรือ **Sub-User** แล้วกด **CREATE**
7. คัดลอก **Access Key** แล้วใส่ใน n8n เป็น **Access Key ID**
8. คัดลอก **Secret Key** แล้วใส่ใน n8n เป็น **Secret Access Key**
    - ดูวิธีสร้าง key และ secret เพิ่มเติมที่ [Creating a Wasabi API Access Key Set](https://knowledgebase.wasabi.com/hc/en-us/articles/360019677192-Creating-a-Wasabi-API-Access-Key-Set){:target="_blank" .external-link}
9. Wasabi แนะนำให้เปิด **Force Path Style** เพราะ path-style ใช้ชื่อ bucket ได้ยืดหยุ่นกว่าและเลี่ยงปัญหา domain name ดูรายละเอียดที่ [REST API Introduction](https://docs.wasabi.com/docs/rest-api-introduction){:target="_blank" .external-link}
10. ตัดสินใจว่าจะให้ n8n credential จัดการ SSL อย่างไร:
    - ถ้าต้องการให้เช็ค SSL certificate ตามปกติ ให้ปิด **Ignore SSL Issues**
    - ถ้าต้องการให้เชื่อมต่อแม้ SSL certificate validation จะล้มเหลว ให้เปิด **Ignore SSL Issues**
