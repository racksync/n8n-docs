คู่มือนี้สรุปชุดของ tutorials และแหล่งข้อมูลที่ออกแบบมาเพื่อช่วยให้คุณเริ่มต้นใช้งาน n8n

ไม่จำเป็นต้องทำทุกรายการที่ระบุไว้เพื่อเริ่มใช้ n8n ใช้สิ่งนี้เป็นข้อมูลอ้างอิงเพื่อนำทางไปยังส่วนที่เกี่ยวข้องมากที่สุดของเอกสารและแหล่งข้อมูลอื่นๆ ตามความต้องการของคุณ

## Join the community

n8n มี community ที่ใช้งานอยู่ซึ่งคุณสามารถรับและให้ความช่วยเหลือได้ เชื่อมต่อ แบ่งปัน และเรียนรู้กับผู้ใช้ n8n คนอื่นๆ:

- [Ask questions](https://community.n8n.io/t/readme-welcome-to-the-n8n-community/44381){:target=_blank .external-link} และ [make feature requests](https://community.n8n.io/c/feature-requests){:target=_blank .external-link} ใน Community Forum
- [Report bugs](https://github.com/n8n-io/n8n/issues){:target=_blank .external-link} และ [contribute](https://github.com/n8n-io/n8n/blob/master/CONTRIBUTING.md){:target=_blank .external-link} บน GitHub

## Set up your n8n

หากคุณยังไม่มีบัญชี ลงทะเบียนเพื่อทดลองใช้ฟรีบน [n8n Cloud](https://app.n8n.cloud/register){:target=_blank .external-link} หรือติดตั้ง n8n's community edition ด้วย [Docker](/hosting/installation/docker.md) (แนะนำ) หรือ [npm](/hosting/installation/npm.md) ดู [Choose your n8n](/choose-n8n.md) สำหรับรายละเอียดเพิ่มเติม

## Structured Courses

n8n มีคอร์สเรียนสองชุด

### Video courses

เรียนรู้แนวคิดหลักและฟีเจอร์ n8n พร้อมสร้างตัวอย่างไปพร้อมกัน

- คอร์ส [Beginner](https://www.youtube.com/playlist?list=PLlET0GsrLUL59YbxstZE71WszP3pVnZfI){:target=_blank .external-link} ครอบคลุมพื้นฐานของ n8n
- คอร์ส [Advanced](https://www.youtube.com/playlist?list=PLlET0GsrLUL5bxmx5c1H1Ms_OtOPYZIEG){:target=_blank .external-link} ครอบคลุม workflows ที่ซับซ้อนมากขึ้น, nodes ที่มีความ technical มากขึ้น และฟีเจอร์ enterprise

### Text courses

สร้าง workflows ที่ซับซ้อนมากขึ้นพร้อมเรียนรู้แนวคิดหลักไปพร้อมกัน รับ badge และ avatar ในโปรไฟล์ community ของคุณ

- [Level 1: Beginner Course](https://blog.n8n.io/announcing-the-n8n-certification-course-for-beginners-level-1/){:target=_blank .external-link}
- [Level 2: Intermediate Course](https://blog.n8n.io/announcing-course-level-two/){:target=_blank .external-link}
