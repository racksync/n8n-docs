# User management

User management ใน n8n ช่วยให้คุณสามารถเชิญผู้คนเข้ามาทำงานใน n8n instance ของคุณได้ ซึ่งรวมถึง:

* การจัดการ Login และ password
* การเพิ่มและลบ users
* สาม [account types](/user-management/account-types.md): **Owner** และ **Member** (และ **Admin** สำหรับ Pro & Enterprise plans)

/// note | Privacy
ฟีเจอร์ user management ไม่ได้ส่งข้อมูลส่วนบุคคล เช่น email หรือ username ไปยัง n8n
///
